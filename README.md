# 13班网页 · 青春档案

班级成员档案网站（Node.js + Express + SQLite 版）。

## 在线预览（静态页面）

https://2407734521m-lgtm.github.io/13班网页/

> 注意：GitHub Pages 只能托管静态文件，无法运行后端的 `server.js`，
> 所以在线预览版的注册 / 登录功能不可用。完整功能需要在自己的服务器上运行。

## 完整运行（需要一台服务器）

```bash
npm install
node server.js
# 打开 http://localhost:3000
```

第一个注册的用户自动成为超级管理员。
